# Automotive Skills Assessment & Candidate Readiness Platform (Australia)

An enterprise-grade assessment, qualification verification, and EV-readiness diagnostic platform tailored for the Australian automotive mechanical and electrical repair sector (aligned with AUR Release 9.0 standards).

---

## Getting Started

### 1. Prerequisites
- **Node.js**: v20.x or higher
- **pnpm**: v10.x or higher
- **Supabase**: PostgreSQL database instance with Auth and Storage

### 2. Environment Configuration
Copy the template environment file and populate your project-specific values:
```bash
cp .env.example .env.local
```

| Variable | Scope | Description |
| :--- | :--- | :--- |
| `NEXT_PUBLIC_SUPABASE_URL` | Public (Client + Server) | Supabase project REST & Auth URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Public (Client + Server) | Supabase publishable anonymous key (governed by Postgres RLS) |
| `SUPABASE_SERVICE_ROLE_KEY` | **Strictly Server-Only** | Admin secret key bypassing Postgres RLS |
| `SUPABASE_SECRET_KEY` | **Strictly Server-Only** | Alias for admin service role key |
| `GEMINI_API_KEY` | **Strictly Server-Only** | Google Gemini 3.5 API key for document OCR and verbal audio analysis |
| `BREVO_API_KEY` | **Strictly Server-Only** | Brevo transactional email API key |
| `BREVO_SENDER_EMAIL` | **Strictly Server-Only** | Verified sender email address |
| `BREVO_SENDER_NAME` | **Strictly Server-Only** | Display sender name |
| `NEXT_PUBLIC_APP_URL` | Public (Client + Server) | Base canonical application URL (e.g. `http://localhost:3000`) |

### 3. Development Server
Run the local development server:
```bash
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

## Security Policy & Secrets Management

> [!CAUTION]
> **CRITICAL SECURITY ADVISORY — GIT HISTORY SECRET ROTATION NOTICE**
> 
> If any API keys, service role tokens, email passwords, or database credentials were ever placed in local configuration files, test scripts, or git commits during prior development cycles, **those values may persist in local git reflogs or repository commit history**.
> 
> **Immediate Action Required for Production Deployment:**
> 1. **Rotate all third-party API keys** immediately (Google Gemini API keys, Brevo transactional API keys, and Supabase service-role secrets).
> 2. **Never commit `.env` or `.env.local` files**. Ensure `.env*` remains in `.gitignore`.
> 3. Verify that no private keys or service tokens are ever prefixed with `NEXT_PUBLIC_`.
> 4. Ensure any administrative clients (`createAdminClient`) remain strictly guarded with `import "server-only";` to prevent client bundle leakage.

---

## Architectural Security Rules
- **Zero Client-Side Secrets**: Only `NEXT_PUBLIC_` variables are accessible in browser bundles. All elevated operations are gated in Next.js Server Actions (`"use server"`).
- **Postgres Row Level Security**: All 25 database tables and all Supabase storage buckets enforce RLS policies. The public anonymous key cannot bypass table or bucket ownership rules.
- **Cryptographic Randomness**: All temporary passwords and organization invitation codes must be generated using `node:crypto` CSPRNG (`randomInt`, `randomBytes`), never predictable PRNGs (`Math.random()`).
- **Human-in-the-Loop Governance**: AI scoring and critical safety flags generated by Gemini models are provisional and must be reviewed and accepted by an accredited human examiner prior to final competency certification.
